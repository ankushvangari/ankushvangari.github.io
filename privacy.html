Privacy policy

bob is a private, personal assistant used only by its owner.

  • It reads the owner's own Gmail and Google Calendar read-only, only to answer the owner's own questions. It cannot send, edit or delete anything.
  • No data is sold, shared with third parties, or used for advertising.
  • Data stays on the owner's computer, except text sent to the AI model provider to answer a request.
  • Google user data is handled in line with the Google API Services User Data Policy, including its Limited Use requirements.
  • Access can be revoked at any time at myaccount.google.com/permissions.
